This project distributes a modified selection of SCOWL. The source permits
use, copying, modification, distribution, and sale under its retained notices.
See the complete Copyright file for all underlying source notices and terms.
The original source files and their checksums are retained with the project.
No competitor word list or game asset was used as a vocabulary source.

Selection: English and American lower-case word lists through SCOWL level 60;
exactly four ASCII letters; project content exclusions; retain the connected
component that can reach POOP by changing exactly one letter per move. Proper
name lists, abbreviation lists, contractions, and special-category lists are
not included. Some rare and inflected words remain accepted. A word omitted
from this practice dictionary may still be valid English.

Familiar-word routes use an independently reviewed project selection, checked
against the licensed dictionary. The selection is not a measured frequency
ranking and does not guarantee that every reader knows every selected word.
A route using this smaller selection may need more moves.

Practice answers are generated with breadth-first search, using the same
versioned dictionary as the game and solver. A shortest path is shortest within
that dictionary. The source is a pinned 2020 release, not the newest release.
Compatibility with any official Poople game has not been verified. Practice
puzzles are reusable examples, not an official daily puzzle feed.

Vocabulary data and practice selections do not create additional content pages.
